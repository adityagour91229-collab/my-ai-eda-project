🔍 Key EDA Techniques
1. Data Cleaning
Data cleaning is used to improve the quality of a dataset.
Common techniques include:
•	Handling missing values
•	Removing duplicate values
•	Correcting data types
•	Data normalization
•	Handling inconsistent data
•	Data imputation
2. Descriptive Statistics
Descriptive statistics help summarize the main characteristics of data.
Important measures include:
•	Mean
•	Median
•	Mode
•	Minimum
•	Maximum
•	Range
•	Variance
•	Standard Deviation
3. Data Visualization
Visualization helps us understand data using graphs and charts.
Common visualization techniques are:
•	Histogram
•	Bar Chart
•	Line Chart
•	Scatter Plot
•	Box Plot
•	Violin Plot
•	Correlation Heatmap
4. Correlation Analysis
Correlation analysis helps identify the relationship between variables.
Common methods include:
•	Pearson Correlation
•	Spearman Correlation
•	Pairwise Relationship Analysis
5. Outlier Detection
Outliers are unusual observations that are significantly different from other data points.
One common method is the 1.5 × IQR rule.
IQR = Q3 - Q1

Lower Fence = Q1 - 1.5 × IQR

Upper Fence = Q3 + 1.5 × IQR
Outliers should be investigated carefully before removing them because they may contain important information.

🚀 Getting Started
Prerequisites
Before running the project, install:
•	Node.js
•	npm
Check installation:
node --version
npm --version
Installation
Open the project folder in the terminal and run:
npm install
Run the Project
Start the development server:
npm run dev
After running the command, open the local URL shown in the terminal.
Usually:
http://localhost:5173
Build the Project
To create a production build:
npm run build
Preview Production Build
npm run preview
